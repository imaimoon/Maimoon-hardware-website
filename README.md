# Maimoon Hardware — Coming Soon

A simple responsive landing page for maimoonhardware.com.bd.

## Preview locally
Open `index.html` in a web browser.

## Files
- `index.html` — landing page
- `assets/logo.png` — supplied Maimoon Hardware logo

## Publish
Upload the contents of this folder to a GitHub repository, then connect that repository to Cloudflare Pages.
For a plain HTML site, use the repository root as the build output directory and leave the build command blank.
